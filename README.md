# 🏥 Medicine Management System

A full-stack MERN application designed for old-age-home caretakers to manage residents, medicines, medication schedules, stock, and basic medical records in one place.

## ✨ Features

- 👴 Resident management
- 🩺 Medical information management
- 💊 Resident-specific medicine management
- ⏰ Morning, Afternoon, Evening & Night medication schedules
- ✅ Mark medicines as given
- 📝 Medication history
- 📦 Medicine stock tracking
- ⚠️ Low-stock and out-of-stock status
- 🔄 Medicine restocking
- 👨‍⚕️ Doctor visit records
- 📌 Follow-up task management
- 🚪 Resident admission & exit management
- 📊 Dashboard with medication and stock overview

## 🛠️ Tech Stack

**Frontend**
- React
- JavaScript
- CSS
- React Router
- Vite

**Backend**
- Node.js
- Express.js
- REST API

**Database**
- MongoDB
- Mongoose
